# Xindoze

**The old paradigm ran code. Xindoze runs intent.**

Xindoze is a local-first operating system. Its apps are prompts (Genomes), its capabilities are MCP tools (Organs), and its intelligence is an ensemble of local open-weight models run through Ollama or llama.cpp. It runs on Windows, Android and Linux through the Universal Bridge, and boots bare metal as a Native Edition. It uses no API keys, no accounts and no cloud.

*Evolve or be emulated. Our revenge is that it works.*
